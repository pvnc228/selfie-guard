# Local data

Put here only images you are allowed to use for the chosen study. Keep sources
unchanged and store derived files separately.

Everything in `data/` except this file is excluded from Git. Keep weights in
`models/` and results in `runs/`; those directories are excluded too.

Do not include personal photos, embeddings, masks or generated results in issues, CI
artifacts, external logs or bug reports. Published examples need a separate prepared
set with suitable rights.

A retention and deletion policy has not been defined. Git ignore rules do not encrypt
files or limit access by other programs on the device.
